# Atividade de Estruturas de Dados

O projeto implementa:

- Pilha para o histórico de navegação.
- Fila para o atendimento de clientes.

As estruturas foram criadas manualmente com vetores. O código não utiliza `array_pop()` nem `array_shift()`.

## Como executar

Abra o terminal nesta pasta e execute:

```text
javac *.java
java Main
```

É necessário ter o JDK instalado e o caminho da pasta `bin` configurado na variável `PATH`.
